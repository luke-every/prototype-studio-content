# Fonts

The licensed `.woff2` files are committed here, so a clone has everything `src/app/layout.tsx` loads:

- `ABCDiatype-Regular.woff2` (400)
- `ABCDiatype-Medium.woff2` (500)
- `ABCDiatype-Bold.woff2` (700)
- `ABCMarist-Book.woff2` (400)
- `Marist-Book-Italic.woff2` (400 italic; `/newprototype` copies it from `ABCMarist-BookItalic.woff2` if it's saved under that name)

Keep this repo private: the fonts are licensed.
